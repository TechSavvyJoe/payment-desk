## Required data flow and minimum request review

Local worksheet → disclosed, consented minimum quote inputs → stateless credential broker → ATC → validated result retained locally. Transient computation is distinct from cloud draft storage; choosing local drafts is not consent to transmit location/transaction facts. Refusal preserves the worksheet and leaves national quoting unavailable.

**OPEN — current API schema:** ATC/engineer must map each fact below to an authorized field, type, units, enum, conditional requirement and missing-input error. This is a candidate fact allowlist, not ATC endpoint names or a JSON/wire specification. Approve only necessary fields per supported scenario; reject unknown fields. If a required fact has no supported mapping, block that scenario rather than guess.

| Fact group | Minimum facts to confirm; minimize conditionally |
| --- | --- |
| Locations/situs | Seller/dealer jurisdiction and physical location; buyer residence, registration/garaging location; delivery/possession location and method. Confirm exact address or authoritative locality/boundary ID needed for each component. State/ZIP alone cannot resolve every local boundary; send precise address only when necessary. |
| Transaction | Dealer retail versus private party; cash/finance/lease; resident/nonresident; exemption classification and required certificate facts; prior tax jurisdiction/amount/date and credit eligibility where supported. No certificate images or identity fields by default. |
| Vehicle | New/used, model year, vehicle/body/registration class, title history/state, mileage, fuel/EV, weight/GVWR, cylinders, original MSRP/value where required. Confirm VIN necessity and decoding alternatives; VIN is not allowed by default. |
| Price/trade | Selling price before/after separately typed discounts; currency/cent precision; trade allowance, vehicle/title class/state, eligibility and timing. Keep payoff/equity local unless a documented tax rule needs payoff or negative-equity treatment; allowance and equity are different facts. |
| Fees/products | Separately stated dealer document/other charges and service-contract/GAP/other product categories, amounts and relevant classification. Registration new/transfer/renewal, plate class, lien and title conditions. Confirm government fees supplied versus calculated; never send arbitrary product names/free text. |
| Rebates/date | Separate manufacturer, dealer and third-party reimbursement/discount types and amounts. Deal/sale date plus delivery/title/registration processing dates where legally relevant; confirm timezone and effective-date selection. |

Exclude names, contact details, SSN, DOB, license/bank/credit records, staff identifiers, vehicle-description free text, full drafts, inventory catalog and financing rate/term/down-payment by default. Any additional necessary fact requires an explicit schema/necessity/privacy review before allowlisting. Non-payload request correlation and scoped dealer/device entitlement metadata must be separately defined; fingerprints stay local unless expressly required.

## Required typed result semantics (adapter requirements, not a wire contract)

| Requirement | Engineering acceptance |
| --- | --- |
| Status | Closed discriminated states: `ready`, `needs-input`, `unsupported`, `rules-expired`, `rules-unavailable`, `invalid-rules`. Non-ready includes safe reason codes, missing fact IDs and retryability; no usable complete tax total. Only fully applicable validated results become `ready`; HTTP success alone is insufficient. |
| Scope/provenance | Resolved collecting/destination jurisdictions and local IDs; supported transaction/vehicle/registration classes; provider/schema/rules revision, effective interval, quote time, expiry/review deadline and source/reference evidence. Separate collection obligation from remaining destination liability; unresolved obligations block completion. **OPEN:** ATC's available provenance and validity guarantees. |
| Input binding | Local canonical fingerprint over all rule-relevant facts, including location resolution, dates, price/trade/items and adapter/capability version; request generation binds delayed responses. Reject mismatched inputs, jurisdictions or versions. Do not log fingerprints derived from sensitive inputs. |
| Lines/ownership | Stable line IDs, category (state/local tax, government fee, dealer charge, credit), jurisdiction, taxable base, rate/cap where applicable, amount and inclusion in totals. Record one authoritative owner per line. ATC tax/DMV lines replace corresponding local lines; dealer charges remain local once, with validated tax treatment. Never add both provider totals and their components or carry MI CRV/title/transfer defaults nationally. |
| Money/rounding | Explicit currency, exact decimal/rational rate precision and bounded integer cents at the app boundary. Confirm line/base/aggregate rounding order, tie rules, credits and statutory minimums; reconcile sum of owned lines to totals. Return/report legitimate adjustments explicitly. Reject unexplained discrepancies; do not recompute every component with MI basis-point precision. |
| Validity/errors | Exact-input reuse only within both legal effective interval and explicit quote expiry, with approved capability/schema. Unknown values remain unknown, never zero. Validate malformed payloads, warnings, semantic errors inside successful responses and unexpected components. |
| Idempotency/retries | Non-mutating quote operation; confirm provider request correlation, duplicate billing/idempotency semantics and limits. Retry identical inputs with the same logical request token only where supported; changed inputs use a new generation. Bounded backoff for approved transient failures; no retry loops for missing inputs/unsupported cases. Timeout, authentication, quota and provider errors map to incomplete status with safe messages. **OPEN:** actual ATC guarantees; do not invent headers or endpoints. |

Persist result/provenance locally only. Worksheet, grid, solver, copy, PDF and print must use the same accepted snapshot and completeness gate; remove Michigan-specific assumptions for other jurisdictions. Preserve the estimate-only qualification and lender/dealership verification boundary.

## Integration and operational acceptance

1. Preserve MI scope gates until each new branch is accepted; never substitute MI, a generic ZIP rate or user-entered percentage for national automotive resolution.
2. Debounce rule-input edits; cancel/discard superseded responses and cap concurrent calls. Grid rate/term/down-only variations may reuse one exact tax result only after provider/policy confirmation that those variations do not change tax/fees; otherwise quote distinct scenarios. Price/product/trade/location/date/rebate/registration changes require fresh applicable results.
3. Current price/product solvers repeatedly invoke `calculateDeal` and assume monotonic metrics. Confirm provider batch/what-if or supported local evaluation rights, call budget and discontinuity behavior before adapting them. Every changed taxable candidate requires its own quote; do not run an unbounded API search. Requote and reconcile the final candidate before applying/exporting it; disable an unsupported target operation explicitly. **OPEN:** ATC scenario capabilities, monotonicity evidence and solver call budget.
4. Offline/timeout/quota/auth errors preserve local edits and block new national results. An exact-input unexpired locally retained quote may be shown only under approved reuse terms, labeled with quote time and offline/reused status; changed/expired results cannot qualify exports. Local MI calculation remains confined to its explicitly admitted policy/scope.
5. Track schema/capability/rules changes and invalidate affected reuse. Unknown versions or conflicting sources block affected scenarios; rollout/rollback must preserve explicit unsupported jurisdictions and local drafts. Approve atomic adapter/capability updates and compatible app/extension releases; no downloaded executable rules.
6. Use the [synthetic matrix](NATIONWIDE-COVERAGE.md), plus refusal/minimization, no-secret/no-payload-log evidence, timeout/quota/HTTP-success-error cases, races, duplicates/retries, line reconciliation and consistent grid/solver/export results.
